# Mustafa Umut Özbek · Academic and engineering portfolio

This directory is a standalone GitHub Pages site. Open `index.html` to preview it locally. The site uses HTML, CSS, and local image assets. The existing OTCyberAI application stays in its own repository.

## Publish

Publish the contents of this directory at the root of the `mumutozbek/mumutozbek.github.io` repository, including `.nojekyll`. In the repository's **Settings → Pages**, select **Deploy from a branch**, `main`, and `/ (root)`. Check that the Pages deployment succeeds before sharing the URL.

The canonical URLs, social preview, profile structured data, and sitemap assume `https://mumutozbek.github.io/`. Update them together if the public hostname changes.

## Content and assets

The profile and public CV were prepared from the existing OTCyberAI profile and the supplied graduate research and nuclear engineering CVs. The originals are kept outside the site. The CV uses year ranges for industry roles whose exact months vary between versions.

- `assets/portrait.jpg`: Portrait from the existing OTCyberAI public portfolio.
- `assets/simulator.jpg`: Screenshot from the existing OTCyberAI nuclear plant training simulator.

When `cv.html` changes, regenerate `assets/mustafa-umut-ozbek-cv.pdf` with the browser's print-to-PDF option using Letter paper and disabled browser headers and footers. The public CV shares an academic email address and public profile links.
